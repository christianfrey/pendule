# Pendule

Pendule is a Google Chrome extension developed between 2009 and 2011, designed to enhance the browser's built-in Developer Tools. It aimed to provide web developers with a suite of additional utilities to streamline their workflow.

At its peak, Pendule had over 100,000 active users and was recognized as one of the top Chrome extensions for developers.

It was the first extension to offer a fully functional color picker for Chrome, alongside many practical web development tools.

## Features

Pendule offered a comprehensive set of tools, including:

- **CSS Tools**: View and reload CSS, disable styles, and beautify CSS code.
- **HTML Tools**: Inspect and validate HTML, remove attributes, and convert form methods between POST and GET.
- **JavaScript Tools**: View and format JavaScript code, and validate JavaScript.
- **Accessibility Tools**: Validate accessibility using WAI guidelines.
- **Form Tools**: Enable disabled form elements, clear radio buttons, and convert select elements to text inputs.
- **Image Tools**: Hide all images, view image information, and display alt text.
- **Color Tools**: Display used colors and include a fully functional color picker.
- **Miscellaneous Tools**: Show passwords, remove cookies for the current site, display window and viewport size, resize the browser to various screen sizes, and display a ruler.

Pendule aimed to simplify common developer tasks by providing handy features not originally available in Chrome’s developer toolbox.
