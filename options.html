Features

Style sheets
  • View styles – displays linked and embedded style sheets of the current page in a new tab.
  • Reload CSS – reloads the style sheets for the current page on the fly, so you don't have to reload the whole page for each change.
  • Disable CSS – disables CSS for the current page.
JavaScript
  • View scripts – displays linked and embedded scripts of the current page in a new tab.
Forms
  • Show passwords – shows the contents of password fields.
  • Select tags to text inputs – converts select elements to text inputs.
  • Remove maxlength – removes maxlength restrictions from inputs.
  • Clear radio buttons – clears all radio buttons.
  • Convert GETs to POSTs – converts form methods from GET to POST.
  • Convert POSTs to GETs – converts form methods from POST to GET.
Images
  • View images – shows images details in a new tab.
  • Hide images – hides all images for the current page.
  • Show alt text – shows images alternative text for the current page.
  • Show dimensions – shows images dimensions for the current page.
  • Show paths – shows images paths for the current page.
Miscellaneous
  • View source – the same as built-in view source (Ctrl+U).
  • View selection source – shows selection source in a new tab.
  • View generated source – shows generated source in a new tab.
  • Color picker – shows the color picker in the current tab. Click on the screen to grab a color in RGB and hexadecimal formats.
  • Display ruler – displays a ruler in the current tab. Select any part of the web page to measure the area within the box that you draw.
  • Topographic view – shows the nesting level of every element using shading.
    Shades the body element black, children of the body dark gray, and so on for up to fifteen layers of nesting.
    Beyond sixteen layers of nesting, shades every element pink. Since each element is slightly lighter than its parent, it is easy to see the extent of each element at a glance.
    The overall brightness of a page can give you an idea of how complex a page's markup is. Since this feature doesn't add borders, it preserves layout to the pixel.
Accessibility

Submits the URL for the currently viewed page to the validator for processing – results appear in a new tab.
Markup & CSS validators work with local files (file scheme, as well as local IP addresses with http scheme).

  • Markup validator – URI: http://validator.w3.org/check?verbose=1&uri=.
  • CSS validator – URI: http://jigsaw.w3.org/css-validator/validator?profile=css21&uri=.
  • Link checker – URI: http://validator.w3.org/checklink?uri=.
  • Feed validator – URI: http://validator.w3.org/feed/check.cgi?url=.
  • WAI validator – Cynthia Says or AChecker.

Tip: each feature that modify (or add something to) the web page can be undone by re-clicking the item.

FAQ

Why the extension does not work on the Chrome Extension Gallery?
For security reasons Google Chrome doesn't support running content scripts on the Chrome Extension Gallery (more details).

Where is section 508 validator?
Section 508 as a specification is 30 years old, so I won't put it in the extension. Instead, use the WAI validator.

Will you implement things like cookies manipulation?
Everything that is already available in the "Developer Tools" (Ctrl+Shift+I) which is built into Chrome won't be implemented.

Could you add WTFramework?
I just can't add WTFramework because content scripts (which is used with this extension) execute in a special environment called an isolated world.
They have access to the DOM of the page they are injected into, but not to any JavaScript variables or functions created by the page (can't read variable jQuery.fn.jquery for example).
A workaround would be analyzing script tags inside the web page (this is the method used by BuiltWith extension), but some information (framework version) would be hard to retrieve.
